## Modifier le site sans code

1. Va sur [app.pagescms.org](https://app.pagescms.org) et connecte-toi avec ton compte GitHub.
2. Ouvre ce dépôt.
3. **Réalisations** : ajoute, modifie ou réordonne tes projets.
   **Mes infos et À propos** : textes, compétences, expériences, CV.
4. Clique sur **Save** : le site en ligne se met à jour tout seul en une à deux minutes.

Petites astuces :
- Dans les textes, mets un mot *entre étoiles* pour le passer en rose.
- Laisse une ligne vide entre deux paragraphes.
- L'**identifiant** d'un projet sert d'adresse à sa page : pas d'espace ni d'accent (ex. `maison-arlette`).
- Tant qu'aucun CV n'est ajouté, les boutons « Télécharger le CV » restent cachés.

## Organisation

- `content/` : les textes et les projets (modifiés par Pages CMS)
- `assets/uploads/` : les images et le CV ajoutés depuis Pages CMS
- `assets/css`, `assets/js` : le design et les animations
